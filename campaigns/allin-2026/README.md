- « Partenaire confirmé » dans la liste ne démontre ni besoin de BETA Labs, ni budget, ni présence de l’acheteur économique.
- Le nombre de contacts 1er degré vient d’un export réseau mentionné mais non joint ; les colonnes enrichies sont conservées comme assertions du snapshot.
