# Décision : enrichissement par agents avant Clay, et nom de Statera Spirits (HOP 2026, Desjardins)

- Date : 2026-10-20 (America/Toronto)
- Décideuse : Elizabeth (BETA Labs)
- Contexte : machine événements, HOP 2026 ; sélection Desjardins (S55). Une table Clay complète était jugée trop lourde pour 27 entreprises.
- Forme : décisions données en conversation de travail avec l'assistant, retranscrites sans modification de sens.

## Décisions

1. L'enrichissement (effectif, province du siège, franchise, dirigeant principal) se fait d'abord avec des agents de recherche, sans Clay. Clay ne sert ensuite, au besoin, qu'à vérifier les effectifs.
2. Une étape distincte estimera ensuite le chiffre d'affaires des comptes restés vides, par calcul à partir d'indices publics (années d'existence, prix, nombre de clients ou de commandes, etc.). Les agents d'enrichissement rassemblent déjà ces indices, sans estimer.
3. Le compte nommé jusqu'ici Gestion PDV est Statera Spirits (https://stateraspirits.com/). Le nom Gestion PDV n'est plus utilisé.
