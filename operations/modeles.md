# Modèles de collecte

Ces fiches sont des modèles à compléter, sans faits client inventés.

## Fiche partenaire / édition

```text
Event ID / édition :
Date annoncée et date vérifiée :
Organisateur / contact / décideur :
Source officielle :
Composition acheteurs / fournisseurs :
Programme exposants / commanditaires :
Statut du partenariat et preuve :
Partage de revenus et base de calcul :
Conditions d’accès à la liste :
Usages, destinataires, conservation et suppression convenus :
Calendrier réel d’introduction et livraison :
Capacité acceptée et responsable :
Points à confirmer :
```

Le champ de traitement des données appelle les conditions réelles du contrat. Il ne crée pas une politique de conservation ni une attestation de conformité.

## Fiche commanditaire

```text
Compte / Event ID / participation vérifiée :
Décideur et rôle de budget :
Besoin commercial / contrat client type / ACV :
Préparation interne existante :
ICP : entreprise, rôle, technologie, signal d’achat :
Exclusions et clients déjà connus :
Quantité disponible / quantité vendue :
Prix unitaire / minimum / exception / devise / taxes :
Date d’accord / dépôt vérifié / livraison :
Capacité et échéance acceptées :
Prochaine action et preuve requise :
```

## Résultat post-événement / cas client

```text
Événement, période observée et commanditaire :
ICP et mode de qualification :
Matchs livrés :
Profils utilisés :
Messages envoyés par le commanditaire :
Réponses / rendez-vous / conversations tenues :
Définition d’une conversation qualifiée :
Opportunités et définition :
Source de la mesure / nombre de répondants / données manquantes :
Autres canaux ayant contribué :
Temps de production et coûts :
Verbatim exact / propriétaire :
Permission de diffusion, date et périmètre :
Limites de l’interprétation :
```
