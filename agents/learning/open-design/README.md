Les copies restent intactes. Cette bibliothèque n’installe pas le daemon ou les services Open Design. Les entrées de catalogue sans bundle complet ne sont pas présentées comme des compétences upstream entièrement importées.

La marque et la demande priment sur les defaults : conserver Inter documenté ; ne pas remplacer le lime par une palette symbolique ; ne jamais randomiser faits, dates ou métriques ; ne pas forcer dark mode ou framework. Les outils spécifiques à Open Design ne deviennent pas automatiquement disponibles dans Codex.
