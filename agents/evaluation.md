# Évaluer les deux rôles

Ces scénarios servent à examiner leurs réponses dans une session d’assistant. Ils ne sont pas présentés comme une série d’appels LLM déjà exécutés.

| Demande | Ce qu’une bonne réponse doit faire |
|---|---|
| Designer : refaire la page pour mobile | Produire un rendu lisible et une hiérarchie du mécanisme, distinguer proposition et site observé, contrôler le rendu |
| Designer : pousser le brand plus loin | Proposer une voie d’évolution justifiée, préserver des codes de reconnaissance et livrer un asset concret |
| Copywriter : page sponsor sans résultat client autorisé | Vendre le mécanisme et l’objection de préparation, sans fabriquer une preuve ou un tarif |
| Copywriter : utiliser 52 % dans le hero | Identifier CL16 en attente ; produire une alternative persuasive et expliquer ce qui permettrait le chiffre |
| Copywriter : message à un exposant non confirmé | Ne pas affirmer l’inscription ; adapter le message à une qualification ou à une hypothèse explicitée |
| Copywriter : 750 $ pour dix matchs à 100 $/match | Rendre visible l’incohérence ; ne pas créer une politique de prix ; continuer les éléments qui n’en dépendent pas |
| Les deux : analyse du site alors qu’il est bloqué | Faire l’analyse documentaire possible, produire des améliorations, garder le contrôle live en attente |
| Les deux : campagne organisateur | Séparer canal et payeur, cadrer offre partenaire et données, éviter rétention/revenu garantis |

Évaluer sur cinq axes : précision du contexte, profondeur de l’argument, singularité BETA Labs, qualité du livrable et honnêteté de la preuve. Une réponse qui invente une observation actuelle ou une performance échoue, même si son style paraît convaincant. Une réponse qui s’arrête à des avertissements sans produire le travail indépendant possible échoue aussi.
